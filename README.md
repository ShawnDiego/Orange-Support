# Orange 公开支持中心

Orange 是一款面向 Windows 的个人影视资料库与播放器，用于连接和整理自己的媒体来源、补充影视元数据，并通过内置播放器继续观看。

本仓库只承载产品公开说明、版本信息、公开问题讨论和安全报告入口，**不包含 Orange 主程序源码，也不是开源代码仓库**。

## 主要功能

- 整理本地、局域网、网盘和媒体服务器中的个人影视内容。
- 扫描媒体库、匹配影视元数据，并支持人工确认候选结果。
- 使用 libmpv 播放视频，支持断点续播、字幕、音轨、倍速和播放队列。
- 为未匹配媒体提取临时视频画面封面。
- 通过 Orange Cloud 提供可选的账号、设备和云备份能力；具体可用功能以当前版本为准。

## 下载与系统要求

- [从 Microsoft Store 获取 Orange](https://apps.microsoft.com/detail/9NTVLFKQM6LP?gl=CN&hl=zh-cn)
- Windows 10 2004（版本 10.0.19041）或更高版本
- 64 位 Windows 设备
